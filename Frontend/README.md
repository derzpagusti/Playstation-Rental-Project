# NovaPS – PlayStation rental website

```
novaps/
├── index.html                    Home (guest + logged-in view)
├── pages/
│   ├── login.html
│   ├── signup.html
│   ├── forgot-password.html
│   ├── time-remaining.html       Time Remaining Status (needs login)
│   ├── order-status.html         Order history + status tabs (needs login)
│   ├── order-form.html           Order Form (needs login)
│   ├── payment.html              QRIS payment + 5 minute timer (needs login)
│   ├── order-detail.html         Receipt / order detail (needs login)
│   └── account.html              My Profile (needs login)
├── src/                          Tailwind sources (edit these)
│   ├── partials/
│   │   ├── shared.css            Theme, buttons, variants (every page)
│   │   ├── navbar.css            Logged-in navbar icons + tooltip
│   │   ├── forms.css             Text inputs (profile, order form, payment)
│   │   └── tabs.css              Status tabs
│   └── <page>.css                One entry per page
├── assets/img/qris.png           QRIS code shown on the payment page
├── css/                          Generated by Tailwind – one file per page
├── js/
│   ├── shared/
│   │   ├── session.js            Login state + saved profile (every page)
│   │   ├── navbar.js             Profile menu + logout
│   │   ├── validation.js         Form validation
│   │   ├── image.js              Image resize helper
│   │   ├── orders.js             Stock, orders, 5 minute payment timer
│   │   └── tabs.js               Tab behaviour
│   └── <page>.js                 One file per page
├── scripts/build-css.js          Builds every src/<page>.css into css/
└── package.json
```

Each page loads only its own CSS and JS, plus the shared JS it needs.

## Run

Open `index.html` in a browser. `css/` is already built.

## Edit with Tailwind

```
npm install        # once
npm run dev        # rebuilds every css/*.css while you edit
npm run build      # build + format css/ with Prettier
```

New page? Add `src/<page>.css` (copy an existing entry) and `npm run build`
picks it up automatically.

## Format code (Prettier)

```
npm run format         # format all files
npm run format:check   # only check
```

Install the "Prettier - Code formatter" extension in VS Code; format on save is
already enabled in `.vscode/settings.json`.

## Deploy (Vercel)

`vercel.json` runs `npm run build` and serves the project root. Commit the
`css/` folder too, so the site also works on hosts that do not build (GitHub Pages).

## Demo notes

Frontend only: login, profile, passwords, stock and orders are NOT stored securely. The login
state and profile live in `localStorage`. Every place that needs a backend API
is marked with `TODO`.
